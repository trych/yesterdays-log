# Changelog

All notable changes to Yesterday's Log will be documented in this file.

## [1.0.0] - 2026-01-06

### Added

- **Count-based filtering**: Show only the N newest files in a folder
- **Age-based filtering**: Show files from the last N minutes/hours/days/weeks/months/years
- **Exclude patterns**: Always hide specific files (e.g., `*.tmp`) and exclude them from counting
- **Auto-refresh**: Automatically updates when files are added, removed, or modified
- **Toggle on/off**: Quickly enable/disable file hiding without changing rules
- **Context menu integration**: Right-click any folder to add a rule
- **Command palette commands**: Add rules, toggle on/off, open settings
- **Global and project rules**: Configure rules in user settings or workspace settings
- **Preserves user settings**: Works alongside existing `files.exclude` patterns
